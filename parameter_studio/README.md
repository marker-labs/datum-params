# DParams Studio

Start from the [repository installation instructions](../README.md), providing a project folder containing saved `.solidcraft` files. Use `--tailscale` to expose the local service to your tailnet, or open http://localhost:8000 on the host. Compose keeps the CAD project read-only. The host preview and URDF workers need `solidcraft-cli`; the first container build compiles the Rust generator.

Select a part in the viewport or assembly list, inspect a feature's dimensions, and add a code parameter. The generated `spec.json`, `parameters.json` and `parameters.hpp` are downloaded to your device. The Python loader expects the exact spec and manifest beside each other in the project's `datum/` directory. Changes to linked CAD invalidate a generated manifest.

## Experimental assembly to URDF

Choose a saved assembly, then **Robot / URDF → Generate and check**. Export runs on the host against a captured copy. Download the ZIP and report after completion. The first profile accepts `solidcraft/34`, millimetres, local linked rigid parts and a rooted occurrence tree with fixed, revolute or slider joints. Unsupported coupled joints are reported as a fidelity failure; export can succeed with a diagnostic bundle. The checker validates basic XML, graph structure, inertials and STL references, but does not establish geometry-cache freshness, source-to-URDF transform equivalence, material accuracy or physics readiness. Freshness is checked at export completion; regenerate after changing a source file. Host worker lifecycle currently requires Linux `/proc`.

The Studio spool is one way to make the URDF lazy. A second, scriptable path skips the spool and the checked-in file entirely: `datum_parameter_studio.lazy_urdf` captures the saved sources, exports into an isolated scratch directory, runs the same structural checker, validates the output bundle for symlinks, containment and size, and returns the URDF text plus a report with source hashes and a freshness result. The result's `bundle` holds the exporter's current output for the captured inputs; `write_bundle`/`--bundle-out` copy the URDF, per-link STLs, assembly STEP and verified part STEP blobs into a directory you keep, since the URDF's relative mesh references need those files beside it. Exporter provenance and fidelity to native CAD are not verified, and this path has no cancellation channel or worker heartbeat (see the [repository README](../README.md#urdf-export-modes) for `bring_up_urdf` and the streaming CLI).

The code is independent of Datum version control. Integrations with Datum snapshots must be supplied separately. Tailscale Serve uses a private tailnet HTTPS endpoint on port 8443; disable it with `tailscale serve --https=8443 off` when no longer needed.
